## 个人签到命令

### 1. 米社游戏签到

**命令格式：**
```
#游戏名签到
#游戏全部签到
```

**支持的游戏：**
- `#原神签到`
- `#崩坏3签到`
- `#崩坏2签到`
- `#未定事件簿签到`
- `#游戏全部签到` (签到所有已绑定的游戏)

**说明：**
- 用于单个用户签到米游社游戏模块
- 需要先绑定 Cookie
- 预计耗时：单个游戏 5-10 秒，全部游戏约 60 秒

**示例：**
```
#原神签到
#崩坏3签到
#游戏全部签到
```

---

### 2. 米游社米游币签到

**命令格式：**
```
#米游社游戏名签到
```

**支持的游戏：**
- `#米游社原神签到`
- `#米游社崩坏3签到`
- `#米游社崩坏2签到`
- `#米游社未定事件簿签到`
- `#米游社大别野签到`
- `#米游社崩坏星穹铁道签到`
- `#米游社绝区零签到`
- `#米游社全部签到` (签到当前用户的所有游戏社区)

**说明：**
- **个人命令**，所有用户可用
- 用于获取米游币（社区签到任务）
- 需要绑定 stoken
- 预计耗时：单个游戏 1-3 分钟，全部游戏 10-20 分钟
- 包括浏览帖子、点赞、分享等任务
- **注意**：`#米游社全部签到` 是个人签到，只签到当前用户的所有游戏社区；`#米币全部签到` 是管理员批量签到命令

**示例：**
```
#米游社原神签到
#米游社全部签到
#米游社崩坏3签到
```

## 批量签到命令

### 1. 米游全部签到

**命令格式：**
```
#米游全部签到
```

**说明：**
- **仅主人可用**
- 为所有绑定的用户进行米社游戏签到（所有游戏）
- 定时任务会在配置的时间自动执行
- 任务开始时会通知主人（从配置文件中读取主人QQ，排除 stdin 适配器）
- 优先签到未标记账号，完成后通知主人
- 再签到标记账号，成功则移除标记，失败则保持标记
- 手动执行时，消息会同时发送给执行命令的用户和配置的主人QQ

**示例：**
```
#米游全部签到
```

---

### 2. 米币全部签到

**命令格式：**
```
#米币全部签到
```

**说明：**
- **仅主人可用**
- 为所有绑定 stoken 的用户进行米游币签到
- 定时任务会在配置的时间自动执行
- 任务开始时会通知主人（从配置文件中读取主人QQ，排除 stdin 适配器）
- 优先签到未标记账号，完成后通知主人
- 再签到标记账号，成功则移除标记，失败则保持标记
- 预计耗时：每个账号约 780 秒（13 分钟）
- 手动执行时，消息会同时发送给执行命令的用户和配置的主人QQ

**示例：**
```
#米币全部签到
```

---

### 3. 云原神全部签到

**命令格式：**
```
#云原神全部签到
```

**说明：**
- **仅主人可用**
- 为所有绑定云原神 token 的用户进行签到
- 定时任务会在配置的时间自动执行
- 任务开始时会通知主人（从配置文件中读取主人QQ，排除 stdin 适配器）
- 预计耗时：每个账号约 3.5 秒
- 手动执行时，消息会同时发送给执行命令的用户和配置的主人QQ

**示例：**
```

```

---

### 4. 逍遥签到（一键开启所有签到）

**命令格式：**
```
#逍遥签到
```

**说明：**
- **仅主人可用**
- 一键启动所有三种签到任务：
  1. 米游全部签到
  2. 米币全部签到
  3. 云原神全部签到
- 三个任务会依次启动（间隔1秒）
- 每个任务都会独立运行，互不干扰
- 所有任务的消息都会同时发送给执行命令的用户和配置的主人QQ
- 适合需要一次性启动所有签到任务的场景

**示例：**
```
#逍遥签到
```

### 2. 强制暂停签到任务

**命令格式：**
```
#强制暂停签到进程
#强制暂停签到任务
```

**说明：**
- **仅主人可用**
- **同时停止所有正在运行的签到任务**（米游币签到、米社签到、云原神签到）
- 任务会**立即停止**，不等待下一个用户签到完成
- 进度会被保存，可以通过恢复命令继续
- 消息会发送给执行命令的用户和配置的主人QQ

**示例：**
```
#强制暂停签到任务
```

---

### 3. 停止签到任务

**命令格式：**
```
#停止签到任务
```

**说明：**
- **仅主人可用**
- **同时停止所有正在运行的签到任务**（米游币签到、米社签到、云原神签到）
- 任务会在下一个用户签到完成后停止
- **注意：进度会被清除，无法恢复**
- 消息会发送给执行命令的用户和配置的主人QQ

**与暂停的区别：**
- 暂停：保存进度，可以恢复，立即停止
- 停止：清除进度，无法恢复，等待当前用户完成

**示例：**
```
#停止签到任务
```

---

### 4. 恢复签到任务

**命令格式：**
```
#恢复签到任务
```

**说明：**
- **仅主人可用**
- 恢复之前暂停的签到任务
- 只能恢复今天暂停的任务
- 会从上次暂停的位置继续执行
- 消息会发送给执行命令的用户和配置的主人QQ

**示例：**
```
#恢复签到任务
```

## 🔄 签到流程说明

### 定时签到流程

1. **定时任务开始**
   - 系统在配置的时间自动开始签到任务
   - 通知主人任务已开始（排除 stdin 适配器）

2. **优先签到未标记账号**
   - 先签到所有未标记为失效的账号
   - 未标记账号全部完成后，通知主人

3. **再签到标记账号**
   - 签到之前标记为失效的账号
   - 如果签到成功，自动移除标记
   - 如果签到失败，保持标记状态

4. **任务完成**
   - 如果有失效账号，会提示主人发送 `#确认删除失效账号` 来删除

### 中断恢复机制

- 如果任务被暂停，进度会被保存
- 可以通过 `#恢复签到任务` 继续执行
- 只能恢复今天暂停的任务
- 恢复后会从上次暂停的位置继续

## ⚙️ 配置说明

定时任务的配置位于：
```
./plugins/xiaoyao-cvs-plugin/config/config.yaml
```

可配置项：
- `mysBbsTime`: 米币全部签到时间（cron 格式）
- `allSignTime`: 米游全部签到时间（cron 格式）
- `cloudSignTime`: 云原神全部签到时间（cron 格式）
- `ismysSign`: 是否启用米币全部自动签到
- `isSign`: 是否启用米游全部自动签到
- `isCloudSign`: 是否启用云原神全部自动签到
- `masterQQ`: 主人QQ号（用于接收签到任务通知，如果不配置则使用系统配置中的主人QQ）

## 📝 注意事项

1. **权限要求**
   - 批量签到命令和任务管理命令仅主人可用
   - 个人签到命令所有用户可用

2. **绑定要求**
   - 米社签到需要绑定 Cookie（包含 login_ticket）
   - 米游币签到需要绑定 stoken
   - 云原神签到需要绑定云原神 token

3. **标记机制**
   - 失效账号会被自动标记
   - 标记账号在下次签到时会被重试
   - 如果重试成功，标记会被自动移除
   - 如果重试失败，标记会保持，需要手动确认删除

4. **stdin 适配器**
   - 所有通知消息会自动排除 stdin 适配器
   - 避免在命令行环境下发送消息

5. **主人QQ配置**
   - 可在配置文件中设置 `masterQQ` 来指定接收通知的主人QQ
   - 如果不配置，则使用系统配置中的主人QQ
   - 所有任务管理命令的消息都会同时发送给执行命令的用户和配置的主人QQ

6. **任务冲突**
   - 如果任务正在运行，重复触发会被拒绝
   - 可以通过暂停/停止命令来中断任务
   - 暂停和停止命令会同时作用于所有正在运行的任务

## 🆘 常见问题

**Q: 如何绑定 stoken？**
A: 发送 `#stoken帮助` 查看详细教程，或直接发送 stoken 格式：`stuid=xxx;stoken=xxx;ltoken=xxx;`

**Q: 如何绑定云原神 token？**
A: 发送云原神 token，格式：`ai=*;ci=*;oi=*;ct=***********;si=**************;bi=***********;devId=***********`

**Q: 签到任务可以中断吗？**
A: 可以，使用 `#强制暂停签到任务` 暂停（可恢复，立即停止所有任务），或 `#停止签到任务` 停止（不可恢复，同时停止所有任务）

**Q: 如何配置主人QQ接收通知？**
A: 在配置文件 `config/config.yaml` 中设置 `masterQQ: 你的QQ号`，所有任务管理命令的消息都会发送给配置的QQ号

**Q: 如何查看签到进度？**
A: 发送 `#签到进度` 或 `#查询进度` 查看当前任务进度

**Q: 失效账号如何处理？**
A: 失效账号会被自动标记，下次签到时重试。如果仍然失败，发送 `#确认删除失效账号` 来删除
